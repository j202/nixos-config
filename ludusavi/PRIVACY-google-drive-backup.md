# Privacy Policy — rclone Google Drive backup (Ludusavi game saves)

This privacy policy applies only to the personal-use Google Cloud OAuth
application used to authorize [rclone](https://rclone.org) for automating
Google Drive backups of local game-save data (see `ludusavi/config.yaml` and
the "Game save backups" section of this repository's README). It does not
apply to this repository, or to anything else in it.

It is used only by its developer, and is not distributed to or used by
anyone else.

**Data accessed**: only files and folders this application itself creates in
the authorized Google Drive account (`drive.file` scope). No other files in
the account are accessed, read, or modified.

**Data storage**: no data is transmitted to, processed by, or stored on any
third-party server. Data flows directly between this application and Google
Drive via Google's own APIs.

**Data sharing**: no data is shared with any third party.

**Developer**: see [github.com/j202/nixos-config](https://github.com/j202/nixos-config).
